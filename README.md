# 单词跟读练习（自用版）

复刻"单词精灵"的英语单词/词组跟读工具，并做了以下增强：

- ✅ 可**自由调整单词前后顺序**（↑↓ 按钮 + 长按拖动）
- ✅ **"带某人/某物"的词组能正确朗读**：`sb.` → `somebody`、`sth.` → `something`
- ✅ **斜杠读作 or**：`give sb. a call / ring` → "give somebody a call or ring"
- ✅ **中英文都能读**：仅英文 / 仅中文 / 英文+中文 三档
- ✅ **手机上可用**（iOS Safari / Android Chrome）

全部离线运行（语音用手机系统自带 TTS），唯一联网点是 Excel 解析库（SheetJS）。

## 在手机上使用

### 方式一：直接打开（最简单）

1. 把 `index.html` 传到手机（微信"文件传输助手"、邮件、网盘均可）。
2. 手机浏览器打开它。
3. 用浏览器"分享 → 添加到主屏幕"（可选），像 App 一样点开。

> 注意：直接打开时，**上传 Excel** 需要联网（加载 SheetJS 库）。不联网也能用「粘贴导入」「载入示例」「手动添加」以及全部跟读功能。

### 方式二：托管到静态空间（体验最好，推荐）

把整个 `word-reader` 文件夹传到任意静态托管：

- GitHub Pages、Vercel、Netlify、腾讯云 COS、阿里云 OSS 等。

手机上用浏览器打开对应网址 → 「添加到主屏幕」，即可全屏使用；后续可加 Service Worker 做成完整离线 PWA（本版未做，见文末）。

## 使用步骤

1. **导入词库**（「词库」页）：
   - 上传 Excel：每个 Sheet 自动变成一个"单元"，三列表头 `单词/词组`｜`中文意思（选填）`｜`音标（选填）`（也兼容 英文/中文/音标 等常见写法）。
   - 或粘贴导入：每行「英文　中文　音标」，用 Tab 或 `|` 分隔。
   - 或载入示例 / 手动新建单元、逐条添加。
2. **调顺序**（可选）：展开单元，长按 ⠿ 拖动，或点 ↑↓。
3. **跟读**（「跟读」页）：勾选要学的单元 → 设置 → 「开始领读」。
   - 朗读语言、顺序/随机、读音次数、播放间隔、跟读停顿、隐藏英文/中文/音标都可调。
   - **点击任意单词即可试听并选中**；选中后再点「开始领读」会从该词开始，领读中点击某词则跳转到该词。
   - 「词库」页展开单元后，点单词文字或 🔊 也能单独试听。

## 朗读处理说明

朗读前会对文本做预处理，保证"带某人"词组和斜杠读得自然：

| 原文 | 朗读为 |
|------|--------|
| `give sb. a call / ring` | give somebody a call **or** ring |
| `serve sth` | serve **something** |
| `give sb. a ride` | give **somebody** a ride |
| `middle / high school` | middle **or** high school |
| `fully booked / full up / full` | fully booked **or** full up **or** full |
| `sb.'s / sb's` | somebody's |
| `call (up)` | call up |
| 中文 `健康中心/卫生院（n. phr.）` | 健康中心**或**卫生院（词性标注自动剥离） |

## 已知限制 / 注意事项

- **iOS 朗读**：首次点"开始领读"会先发一句静音短句"预热"引擎。锁屏或切到后台会停止朗读，**跟读时建议保持屏幕常亮**。
- **长列表**：逐条朗读，若中途卡住点「继续」即可。
- **语音可选**：在「跟读设置 → 语音选择（高级）」里可指定英文/中文语音；不同手机的语音名字不同。
- **Excel 上传需联网**（SheetJS 走 CDN）；不联网请用粘贴导入。

## 后续可优化（按需追加）

1. **完整离线 PWA**：加 Service Worker + manifest，Excel 解析库也本地化，断网也能上传 Excel，并可安装为独立 App。
2. **导出/分享词库**：把当前词库导出为 Excel 或文本。
3. **听写模式**：隐藏英文+中文、只听音标/发音，用于默写。
4. **复习模式**：按错误/收藏标记循环复习、随机抽查。
5. **录音跟读对比**：录下自己的跟读、回放对比原音（需麦克风权限，实现较复杂）。
6. **读音次数更灵活**：例如"英文读 2 遍 + 中文读 1 遍"分别设置。
